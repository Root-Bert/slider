# Google Fonts

The most used Google Fonts, regular, bold, italic and bold italic, as static TrueType files from the
Google Fonts CSS API – installed for LibreOffice in the Docker image; the browser has the same faces
as WOFF2 in `apps/web/public/fonts/office`. Written by `scripts/google-fonts.py`.

Free to use and redistribute: each under the license Google Fonts names for it
(`https://fonts.google.com/specimen/<Family>/license` – the SIL Open Font License 1.1 for most,
the Apache License 2.0 or the Ubuntu Font Licence for a few).
