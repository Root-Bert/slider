Die meisten Teams fangen mit dem an, was schon da ist: Kommentare direkt in PowerPoint. Das geht gut, bis eine Präsentation drei Versionen, zwei Abteilungen und eine Agentur durchläuft. Hier steht, wo welcher Weg seine Stärke hat.

## Der Vergleich

|                               | Kommentare in PowerPoint  | Slider                               |
| ----------------------------- | ------------------------- | ------------------------------------ |
| Pin auf eine genaue Stelle    | Auf Objekten              | Jeder Punkt oder Bereich             |
| Kommentare als Sprache, Video | Nein                      | <span class="ok">✓</span>            |
| Feedback von außen            | Braucht Zugriff auf Datei | Einladen per Mail oder Link          |
| Live sehen, wer da ist        | ✓ gemeinsames Bearbeiten  | <span class="ok">✓</span> mit Folgen |
| Feedback über Versionen       | Bleibt in einer Datei     | Zugeordnet, Änderungen markiert      |
| Eigener Server in der EU      | Nein                      | <span class="ok">✓</span> ein Befehl |

## Wann Kommentare in PowerPoint reichen

Wenn ein oder zwei Leute ein paar Notizen in derselben Datei hinterlassen und niemand von außen hineinsehen muss, sind die eingebauten Kommentare schnell und kostenlos. Sie stecken in der Datei und reisen mit ihr.

## Wann Slider eine Runde spart

Sobald Feedback von mehreren kommt oder von jemandem ohne Zugriff auf euren Ordner, hält Slider alles an einem Ort. Alle sehen jeden Kommentar an der Stelle, um die es geht, können per Sprache oder Video antworten, und wenn du Version 4 hochlädst, folgen die Kommentare ihren Folien.
