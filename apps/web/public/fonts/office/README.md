# Office fonts

The fonts the live editor draws text boxes in – the same Slider's LibreOffice draws slides with,
metric-compatible with Office's (see `apps/web/src/features/viewer/editing/live/fonts.ts` and
`packages/shared/src/office-fonts.ts`). Converted to WOFF2 from the TrueType files LibreOffice
ships, unchanged otherwise.
